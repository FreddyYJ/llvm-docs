Modifies MergedVal to approximate both Val1 and Val2.

This could be a strict lattice join or a more general widening operation. If this function returns true, MergedVal will be assigned to a storage location of type Type in Env.

Requirements:

Val1 and Val2 must be distinct.

Val1, Val2, and MergedVal must model values of type Type.
